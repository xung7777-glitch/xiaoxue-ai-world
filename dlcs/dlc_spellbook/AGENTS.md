# Project-Specific Instructions

## Core Behavioral Directive
- **Strict Command Mode:** Only execute the specific changes requested by the user. Do not "improve," "innovate," or add any features based on "good intentions" if they were not explicitly asked for.
- **No Unsolicited Changes:** NEVER modify any existing functionality, UI elements, or logic unless explicitly requested. If the user hasn't asked to change something, it must remain exactly as it is.
- **Feature Preservation:** All existing features (e.g., sentence indices, specific click behaviors, button labels) must be preserved in their current state during any modification task unless their removal or alteration is the primary goal of the task.
- **Precision over Innovation:** Prioritize exact execution of instructions over creative additions. If a request is ambiguous, ask for clarification instead of guessing or "improving."
